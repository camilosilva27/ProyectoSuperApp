Aplicación web que te permite crear un carrito con prodcutos de supermercados y reparte donde comprar cada uno, 
considerando tus tarjetas, suscripciones, clubes y promociones del supermercado, logrando la compra más óptima.
Se te permite elegir en qué supermercados querés comprar y establecer un máximo de supermercados a visitar, 
en caso de que no quieras dar muchas vueltas. Los niveles de ahorro generales que hemos alcanzado son a partir del 25% en la compra total.
Puede utilizarse para compras grandes, pero también quizás para ver donde comprar algún producto puntual.
